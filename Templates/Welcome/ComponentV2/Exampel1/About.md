# Welcome Components V2

This example sends a Components V2 welcome card when a member joins. It includes a banner image, a divider, a welcome message with the member mention and server member count, and buttons linking to the rules and verification channels.

## Preview

![Welcome card preview](./preview.png)

## Setup

In `index.js`, replace `YOUR_WELCOME_CHANNEL_ID`, `YOUR_RULES_CHANNEL_ID`, and `YOUR_VERIFY_CHANNEL_ID` with the channel IDs from your server. The banner URL in the code is also a placeholder; change it to your image URL.
